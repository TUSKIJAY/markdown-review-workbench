# Markdown 文档审阅标注工作台产品蓝图

## 核心定位

本工具是一个面向内部文档工作的本地 Markdown 审阅标注器，不直接调用 AI API。它负责把用户对文档的局部不满意点、修改意图和原文位置整理为 Agent 可读取的结构化任务文件。

## V0.1 范围

- 读取单个 `.md` 文件。
- 渲染 Markdown 预览。
- 自动提取标题大纲。
- 将标题、段落、列表项、引用块、代码块和表格块解析为可点击审阅块。
- 用户点击审阅块后，在右侧填写修改建议。
- 每条标注记录文件名、标题路径、块类型、行号范围、原文片段、修改建议、优先级和状态。
- 导出 Agent 读取用 `*.ai-notes.json`。
- 导出人工可读 `*.review.md`。
- UI 预留打开文件夹入口，但不作为 V0.1 主流程。

## 非目标

- 不接入 AI API。
- 不直接修改原始 Markdown 文件。
- 不处理 Word、PDF 或复杂富文本格式。
- 不做多人协作、账号系统或远程存储。

## 典型流程

1. 打开本地 Markdown 文件。
2. 在中间预览区阅读文档。
3. 通过左侧大纲快速跳转章节。
4. 点击某个段落或文本块。
5. 在右侧输入修改建议、优先级和状态。
6. 保存为标注。
7. 导出 JSON 或 Markdown 修改清单。
8. 后续让 Agent 读取导出文件并定点修改原文。

## 导出数据原则

- JSON 面向 Agent，字段稳定、可解析。
- Markdown 面向人工复核，便于直接粘贴给 Agent。
- 原始文档默认保持干净，不写入隐藏注释。
